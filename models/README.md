# About This Folder

The files in this (**models**) folder and **outputs** folder are created during the execution of the code.

They are **not required to run the project**.  
All models and outputs can be reproduced by running the provided notebook.

These files are included only for reference, so users can understand the expected outputs and artifacts.

Note: Large generated file (`rf_model.pkl`) is not included in this folder due to repository size limits, but it will be recreated automatically when the code is executed.
